ZIRAN + KRYON

A small browser, built from scratch.

Enter a web address or a file URL above. HTML becomes a document tree, CSS styles that tree, and Kryon draws the page.

Simple pages, clearly rendered

Headings, paragraphs, lists, links, preformatted text and image descriptions work here. Text wraps to the window and the page scrolls independently.

Styles can set colors, backgrounds, font sizes, spacing, widths and visibility using element, class, ID and inline selectors.

A first engine

This early browser supports embedded and inline CSS. JavaScript, forms, image decoding, external stylesheets, flexbox and grid are not implemented yet.

Visit example.com

No Chromium or WebKit rendering engine. Document fetching runs outside the UI thread.
